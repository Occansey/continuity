# Exit criteria

Written before each phase starts, so the bar cannot move once the work is underway.

Every gate is **a command someone else can run**, and its output is the evidence. A gate
that requires the author to be present to interpret it is not a gate.

---

## G0 · The partner is load-bearing

```
python -m evals.partner_benchmark
```

Passes when: three spec questions run against ClickHouse and against a flat-file
baseline, and the report shows both timings and both implementations. The gate does not
require ClickHouse to win. It requires the comparison to exist and be published, so that
the choice is a finding rather than an assumption.

## G1 · No uncited threshold can load

```
python -m evals.spec_lint
```

Passes when: every clause in every spec file has a citation, and a deliberately
uncited fixture clause fails to load with a message naming the clause.

## G2 · Findings are reproducible and re-derived

```
python -m evals.determinism
```

Passes when: the same input and spec produce byte-identical findings across two runs,
and every finding in a report can be re-derived by running its own query against the
store.

## G3 · No repair without earned authority

```
pytest tests/test_authority.py tests/test_wiring.py
```

Passes when: a repair class in rehearsal cannot write; promotion requires verified clean
runs; one failure demotes; and the *server's* dependencies are asserted, not a fixture's.

## G4 · Calibration is reported both ways

```
python -m evals.calibration
```

Passes when: false-pass and false-fail are reported separately with intervals, on a
declared labelled set, and the report states how many labels were synthesised.

## G5 · The submission is checkable

```
./scripts/preflight.sh
```

Passes when: hosted URL returns 200, the ClickHouse calls in `docs/PARTNER.md` resolve to
real lines in real files, the licence exists, and every number in `README.md` is
regenerated by a command listed beside it.
